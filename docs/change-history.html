Release notes

Change history

A release-by-release record of features, fixes, and behavior changes in SQL Debug Harness.

0.0.4 — 2026-08-01

Current release

This release keeps temporary-table DML live in the harness and wraps bare IF / ELSE assignments so variable traces stay inside the intended branch.

Changed

  • INSERT / UPDATE / DELETE against #temp / ##temp tables are left intact (same treatment as table-variable DML).
  • Bare IF / ELSE / WHILE bodies that assign with SET or SELECT @var = … are wrapped in BEGIN…END together with the injected variable trace.

Fixed

  • Traces after single-statement IF / ELSE branches no longer break branch pairing or execute outside the intended path.

0.0.3 — 2026-07-27

Added

  • spDebug.traceStyle values select (default) and printCombined.
  • Workbench Clear clears generated debug script, analysis, and activity log while keeping the loaded source.
  • Workbench Save popover groups Analysis Report, Debug Script, Log File, and Open Debug Script.

Changed

  • Variable traces default to SELECT 'DBG' [NOTES], @var [var], ….
  • print remains one PRINT per variable; printCombined folds multi-variable assignments into one PRINT CONCAT.
  • Procedure AS BEGIN and the matching outer END are stripped from generated harness scripts.
  • Inline first-line parameters continue onto following lines until AS, keeping one continuous DECLARE list.

Fixed

  • Parameters after an inline first-line @param no longer remain as orphaned type lines outside DECLARE.
  • Nested BEGIN / END blocks inside the body are preserved when the outer procedure wrapper is removed.

0.0.2 — 2026-07-25

Added

  • Workspace-scoped history for recently analyzed and debugged stored procedures.
  • Workbench History picker for reopening recent procedures.
  • Grouped, collapsible Identified results by Kind.
  • Distinct SVG icons for each Workbench toolbar action.
  • spDebug.workbenchToolbarStyle with iconsAndText, iconsOnly, and textOnly.

Changed

  • Procedure parameters generate one comma-separated DECLARE.
  • Parenthesized parameter lists and procedure output parameters are supported.
  • The Workbench opens as a normal tab in the active editor group.
  • Analysis and Activity Log collapse from their full headers without reordering.
  • Long SQL and log lines remain unwrapped and scroll horizontally.

Fixed

  • Invalid semicolons between generated parameter declarations.
  • Invalid OUTPUT / OUT tokens in declarations.
  • Parenthesized headers being interpreted as having no parameters.
  • Identified accordions rendering horizontally.
  • Activity Log moving when Analysis was collapsed.
  • History opening the activity-bar sidebar and unavailable SQL horizontal scrolling.

0.0.1 — 2026-07-19

Initial release of the standalone VS Code extension and optional CLI.

  • In-process TypeScript transform and analysis engine.
  • Read-only previews for INSERT, UPDATE, and DELETE.
  • Transaction-control neutralization, named EXEC stubs, and variable tracing.
  • Workbench with source, generated SQL, analysis, and activity-log panes.
  • VSIX packaging and GitHub Pages documentation.
